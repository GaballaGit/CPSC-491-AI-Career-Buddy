# SOC 2 CC6.6 Resume API Assessment (C40CS-70)

Security assessment of the Resume Edge Function boundary for SOC 2 CC6.6 (System
Boundary Protection). This is a verification record: each deficiency has its own
Bug linked to C40CS-70. Fixes are tracked in C40CS-71.

## Result: **Partially Verified**

Authentication, the public health endpoint, the 5 MB upload limit and the
feedback text limit work as intended. File-signature checks, CORS restriction and
rate limiting are missing. Three further boundary gaps were found: the upload
body is read in full before the size check, and `targetRole` and the filename
have no length limit.

## Results by acceptance criterion

| AC                     | Result                 | Evidence                                                                                                                                                                |
| ---------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC1 Authentication     | **Verified**           | Upload, skills and feedback return `401 AUTHENTICATION_REQUIRED` with no header, `Basic invalid` and `Bearer invalid`. Each route authenticates before any data access. |
| AC2 Public health      | **Verified**           | `GET /resume/health` signed out returns `200` with only `status` and `service`.                                                                                         |
| AC3 Upload constraints | **Verified, with gap** | Valid PDF padded to 5 MB − 1 and exactly 5 MB: `200`. 5 MB + 1: `400`. Gap: a 20 MB body is read in full before rejection (**C40CS-77**).                               |
| AC4 File signatures    | **Failed**             | Mismatched files are rejected (`422`) only because the parser fails. No check before parsing (**C40CS-76**).                                                            |
| AC5 CORS               | **Failed**             | `Access-Control-Allow-Origin: *` on every response, including errors and a preflight from `https://evil.example` (**C40CS-78**).                                        |
| AC6 Rate limiting      | **Failed**             | 11 feedback calls in 2 ms: 11 × `200`. 100 parallel calls: 100 × `200` (**C40CS-79**).                                                                                  |
| AC7 Feedback input     | **Verified, with gap** | Text of 50,000 chars: `200`. 50,001: `400`. Gap: a 100,000-char `targetRole` is accepted and sent to the LLM prompt (**C40CS-80**).                                     |
